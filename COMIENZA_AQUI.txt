   Una aplicación web moderna y profesional que funciona como la 
   RESPUESTA del intercambio de amigo secreto para Byron Josué.

   Incluye:
   ✅ Portada elegante con CTA
   ✅ Mensaje de fe y respaldo (tono "bro" auténtico)
   ✅ Sección de juegos con clips de Free Fire y Clash Royale
   ✅ Diseño serio, limpio y masculino
   ✅ Animaciones suaves sin ser abrumador
   ✅ 100% responsivo (mobile, tablet, desktop)

📝 PERSONALIZAR:

   TODO lo que necesitas cambiar está en:
   
      src/components/GamingSection.tsx
   
   En ese archivo encontrarás un array llamado GAMES_DATA con 
   esta estructura:
   
      {
        name: 'Free Fire',
        clips: [
          {
            title: 'Tu título aquí',      ← CAMBIAR
            tag: 'Le gané',               ← CAMBIAR
            roast: 'Tu frase de vacilón', ← CAMBIAR
            imageUrl: 'https://...',      ← CAMBIAR
          },
        ]
      }
   
   CAMBIOS BÁSICOS:
   
   • title:    Describe la jugada
   • tag:      Etiqueta corta (ej: "Acarreado", "Le gané", "Torre")
   • roast:    Frase jocosa/de vacilón
   • imageUrl: URL de tu captura de pantalla
